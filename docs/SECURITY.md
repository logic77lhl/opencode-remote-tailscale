# Security

This document describes the security model of `opencode-remote-tailscale` and the minimum hardening steps.

> **Core mental model:** the OpenCode password is a **remote shell password**. Anyone who has the password, a valid pair link, or a valid session cookie can read/write files and execute commands as your Windows user.

---

## 1. Threat model

| Attacker | Capability | Mitigation |
|---|---|---|
| Random internet scan | Reaches the Funnel login page | Strong random password; no other ports open |
| Someone with the URL | Sees the login page | Password + one-time pair links |
| Someone with a pair link | Can log in once, within 5 minutes | Treat links like passwords; never forward |
| Someone with a stolen cookie | Full access until expiry | 30-day expiry; change password to revoke instantly |
| Someone with your Tailscale account | Can join devices to your tailnet | 2FA on the identity provider |
| Malware on the PC | Can read the cookie/password and session DB | Defender, BitLocker, least privilege |
| Lost/unlocked phone | Can open the home-screen icon | Device passcode/biometrics; revoke by changing password |

---

## 2. External exposure

| Item | Behavior |
|---|---|
| Public ingress | Tailscale Funnel on HTTPS `443` |
| Plain HTTP `80` | Not served by Funnel (connection fails) |
| Router ports | None opened; no public IP required |
| Local listener | `127.0.0.1` only — not reachable from the LAN |
| TLS | Certificates issued and managed by Tailscale |
| Security headers | CSP and `X-Content-Type-Options` are set by OpenCode; no HSTS (HTTP is closed) |

The only publicly reachable service is the OpenCode login page.

---

## 3. Authentication

| Item | Value |
|---|---|
| Username | `opencode` |
| Password | 43-character random string generated by OpenCode |
| Pair link | One-time, expires in 5 minutes |
| Session cookie | `opencode_session`, 30 days, `HttpOnly`, `SameSite=Lax` |
| Cookie signing | HMAC-SHA256 with the password as key |
| Brute force | Infeasible with a 43-character random password |

### Revocation

**Changing the password invalidates every existing cookie immediately**, because the cookie signature is derived from the password.

```powershell
opencode service set password "<new random password>"
```

Use this when:

- a phone is lost or stolen
- a pair link was leaked
- you suspect a cookie was stolen

All devices must scan a new QR afterwards.

### Cookie caveat

OpenCode does not set the `Secure` flag on the cookie. This is mitigated by Funnel not serving plain HTTP, but it is not ideal. Do not expose port 80 through another proxy.

---

## 4. Phone

- Use **Safari / Chrome**, not WeChat/QQ in-app browsers (compatibility and less third-party injection).
- Enable a device passcode and biometrics.
- Do not screenshot or forward the QR/link.
- Remove old home-screen icons when the hostname changes.
- On loss: change the OpenCode password first, then remove the home-screen icon.

---

## 5. Windows host

| Item | Recommendation |
|---|---|
| Account | Use a standard (non-admin) user for OpenCode if possible |
| UAC | Keep enabled; OpenCode runs with a filtered token |
| Defender | Keep real-time protection on |
| Firewall | Keep all profiles on |
| RDP | Keep disabled unless you need it |
| Autologon | Do not enable |
| BitLocker | Enable and back up the recovery key — the session DB is plaintext SQLite |
| Updates | Keep Windows, OpenCode and Tailscale updated |
| Screen lock | Lock when leaving the desk (locking does not break remote access) |
| Sleep | Sleep breaks remote access; AC sleep is disabled by the setup guide, battery sleep may still apply |

---

## 6. Tailscale account

The Tailscale account is the **root of trust** for the tailnet.

- Enable **2FA** on the identity provider (Google / Microsoft / GitHub).
- Review the machine list regularly; remove devices you don't recognize.
- Device keys expire (default ~180 days); re-authenticate when prompted.
- If you only need one phone, consider turning Funnel off and using Serve + the Tailscale app.

## 7. Hardening checklist

### P0 — do today

- [ ] Enable 2FA on the Tailscale account
- [ ] Use a strong Windows login password
- [ ] Know the revocation command: `opencode service set password "<new>"`

### P1 — do this week

- [ ] Turn Funnel off when not needed:
  ```powershell
  $ts = "C:\Program Files\Tailscale\tailscale.exe"
  & $ts funnel --https=443 off
  & $ts serve --bg 28894
  ```
- [ ] Enable BitLocker and store the recovery key
- [ ] Consider a dedicated standard user for OpenCode

### P2 — habits

- [ ] Keep software updated
- [ ] Check the session list for unknown sessions
- [ ] Never forward pair links, passwords, or QR codes
- [ ] Re-run `scripts/restore.ps1` instead of reusing old links

---

## 8. What this repo does not do

- It does not add MFA to OpenCode itself.
- It does not add IP allow-lists or rate limiting to the login page.
- It does not encrypt the OpenCode database (use BitLocker).
- It does not protect against malware already running as your user.

If you need stronger isolation, run OpenCode in a dedicated Windows user or a VM, and expose only that environment.

---

## 9. Reporting

This is a personal automation repo, not a hosted service. If you find a security issue in OpenCode itself, report it to the OpenCode project. If you find an issue in these scripts, open a GitHub issue with reproduction steps and **no secrets**.
